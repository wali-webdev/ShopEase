# ShopEase – E-commerce Store Frontend

A modern and responsive e-commerce website built using HTML, CSS, and JavaScript.

## Features
- Responsive design
- Product search and filtering
- Shopping cart counter
- Wishlist functionality
- Modern UI and animations
- Newsletter interaction

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Purpose
This project demonstrates my frontend web development skills and ability to build interactive and responsive websites.
